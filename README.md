# 전주대학교 도서관 · 도서 오배열 탐지

- **팀 구성** · 6인
- **개발 환경 및 기술(계획)** · 스마트폰 카메라, YOLO 기반 라벨 탐지, OCR 문자 인식
- **개발 상태** · 개발 중
- **목표** · 스마트폰으로 서가를 비추면 잘못 꽂힌 책의 위치를 화면에 실시간으로 표시하는 시제품 개발

## 왜 이 프로젝트를 시작했나

도서관에서 책이 원래 자리가 아닌 곳에 꽂혀 있으면, 청구기호를 알아도 주변 서가를 다시 살펴봐야 합니다. 저희 팀은 이 불편을 줄이기 위해 **스마트폰으로 서가를 비추는 것만으로 잘못 꽂힌 책을 찾을 수 있을까?**라는 질문에서 시작했습니다.

YOLO로 책등의 청구기호 라벨을 찾고, OCR로 라벨에 적힌 문자를 읽는 방식으로 기획했습니다. 화면에서 책이 놓인 순서와 청구기호의 배열 규칙을 비교해, 순서에서 벗어난 책의 위치를 스마트폰 화면에 표시하는 것이 목표입니다.
